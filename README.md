# TLSG – The Last Study Guide

An ocean of learning. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- **Revision** – Create flashcard sets, flip cards, and mark them as known or for review.
- **Timetable** – Colour-coded weekly schedule grid (Mon–Sun, 07:00–21:00).
- **Pacemaker** – Pomodoro timer with daily session targets and a visual progress ring.
- **Study Guide** – Build structured guides with multiple headed sections, organised by subject.

All data is stored in `localStorage` — no backend required.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
